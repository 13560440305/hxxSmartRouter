接入文档

1. 智能路由（推荐）

使用虚拟模型，由策略按任务自动选择真实模型。

curl https://router.example.com/v1/chat/completions \
  -H "Authorization: Bearer $HXX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "hxx/docqa-auto",
    "messages": [{"role":"user","content":"总结这份合同的风险点"}],
    "metadata": {"task_type": "document_reasoning"}
  }'

2. 直接指定模型

所有执行模式下均可指定已授权模型；仍受权限与预算约束。

curl https://router.example.com/v1/chat/completions \
  -H "Authorization: Bearer $HXX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role":"user","content":"Hello"}]
  }'

3. 纯决策接口

只获取路由结果，由业务侧自行调用上游（适合多阶段流水线）。

curl https://router.example.com/v1/route \
  -H "Authorization: Bearer $HXX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "virtual_model": "hxx/docqa-auto",
    "task_type": "embedding",
    "features": {"estimated_tokens": 1200}
  }'
